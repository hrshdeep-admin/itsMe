Virtual Engineering Lab

A 13-project engineering curriculum, built in simulation. This page covers the first seven projects, from a two-wheel rover to a warehouse robot.

Rule for all seven: do not buy hardware.

Predict → Test → Explain. Do this for every experiment, and write the prediction down before you run it.

ToolsOverview

Tools

Standardise on one main simulator so no hobby time is lost installing new ecosystems.

WebotsMain robotics simulator. Open source, with sensors, motors, cameras, physics and example worlds.
FreeCADDefault CAD. Free, local files, native on Apple Silicon and Windows.
WokwiLater: simulate Arduino and ESP32, sensors, LEDs and servos.
Onshape EducationBrowser CAD alternative if you are eligible.
